# Case-Tracker-PowerPlatform

OFC Case Tracker for Oxford Performance Materials, rebuilt on Power Platform (Dataverse + model-driven app) from the legacy Next.js app in `jdef11/Case-Tracker`.

- Plan: [`docs/POWER_PLATFORM_PLAN.md`](docs/POWER_PLATFORM_PLAN.md) (v2)
- Legacy reference: `jdef11/Case-Tracker` (`ofc-case-tracker/`, plus the v1 plan on branch `claude/sweet-wright-az0d4y`)

**No PHI in this repo.** Only anonymized data belongs here. Real exports from the SharePoint list stay in OPM-controlled storage.
